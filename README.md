# The Land That Remembers

Уютная 2D-игра о ремесле, отношениях и возвращении жизни в почти покинутое поселение.

> Здесь ничего не было. Теперь здесь снова живут люди — и я приложил к этому руку.

## Стек

- **Godot 4** (Standard) + **GDScript**
- Отрисовщик: **GL Compatibility**
- Данные квестов/диалогов: JSON в `data/`

## Быстрый старт

1. Установи [Godot 4](https://godotengine.org/download/windows/) (Standard, не .NET).
2. Project Manager → **Import** → укажи эту папку (где `project.godot`).
3. Нажми **F5** (или Play).
4. Читай [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md), если Godot новый для тебя.

## Управление (прототип)

| Клавиша | Действие |
|---------|----------|
| WASD / стрелки | Ходьба |
| E | Взаимодействие |
| Esc | Закрыть диалог |

## Вертикальный слайс (сейчас)

Мастерская → площадь → пекарня. Почини печь Софьи: материалы → верстак → печь → сон → утро с открытой пекарней.
