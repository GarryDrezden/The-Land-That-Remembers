# Roadmap

## Phase 0 — Bootstrap ✅

- Godot-проект в `E:\Работа\OSPanel\domains\the-land-that-remembers`
- Структура папок, git remote, README + docs
- Ходьба по трём зонам

## Phase 1 — Prototype (core loop) ✅ / в полировке

- Верстак + рецепт дверцы
- Софья / Пётр + диалоги с флагами
- Ремонт печи → визуальный diff
- Сон и «утро» пекарни

## Phase 2 — MVP polish

- Более читаемый UI инвентаря
- 2–3 личных заказа вокруг площади
- День/ночь без жёсткой энергии Stardew
- Звук/музыка placeholder, меню паузы

## Phase 3 — Alpha

- Мост квестом (не «500 дерева»)
- Площадь этапами
- NPC: Лада, Миша, Нина (скелет линий)
- Разбор старых вещей
- Черновик отношений: доверие + близость

## Phase 4 — Beta

- Сезоны
- Мельница с каскадным эффектом
- Специализация мастерской (дерево или металл — глубже)
- Конфликт «каким станет поселение» (2 пути)

## Phase 5 — Campaign complete

- Станция, общественный дом, праздник восстановления
- Финал: первое изделие рядом с последним
- Post-game sandbox

## Правило приоритета

Любая механика проходит тест:

> Усиливает ли она ощущение «я вернул жизнь месту»?

Если нет — откладываем или режем.
