# MVP — рамки

MVP = один вертикальный слайс, который доказывает фантазию:

> Я сделал вещь → место ожило → люди ответили иначе.

## Внутри / снаружи

| Есть | Нет |
|------|-----|
| Карта: мастерская → площадь → пекарня | Вся долина, станция, мельница |
| Ходьба, E-взаимодействие, инвентарь | Ферма как основная петля |
| Верстак, дерево + металлолом | Полная модульная мебель |
| Пётр + Софья | Романтика, все NPC из дока |
| Квест: починить печь | Общественный дом, голосования |
| Свет в окне, вывеска, жители утром | Сезоны, 3 шкалы усталости |
| Диалоги по флагам WorldState | Полные доверие/уважение/близость |
| Save в `user://world_state.json` | Наследие, направление поселения |

## Цикл прохождения

1. Холодная мастерская-сарай.
2. Пётр → намёк на печь и материалы.
3. Софья → пекарня закрыта.
4. Забор + телега → дерево и металлолом.
5. Верстак → дверца печи.
6. Печь → `oven_repaired`, тёплый свет.
7. Сон → утро, `bakery_open`, жители, намёк на мост.

## Критерий готовности

Незнакомый человек за 15–20 минут понимает, *зачем* игра существует, без объяснений снаружи.

## Статус реализации

Прототип слайса лежит в `scenes/world/valley_slice.tscn` + `scripts/world/main_slice.gd`.
