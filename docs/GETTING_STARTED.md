# Godot с нуля — для этого проекта

Ты открыл **The Land That Remembers** в Godot. Ниже — минимум, чтобы не потеряться.

## Окно редактора

- **Сцена (слева вверху)** — дерево объектов текущего уровня.
- **Файловая система (слева внизу)** — все файлы проекта (`res://` = корень папки).
- **Центр** — вид 2D / 3D / Скрипт.
- **Инспектор (справа)** — свойства выбранного узла.
- **F5** — запустить игру (главная сцена уже задана).

## Главные слова

| Термин | Простыми словами |
|--------|------------------|
| **Узел (Node)** | Один объект: игрок, печь, надпись |
| **Сцена (.tscn)** | Файл-уровень или префаб из узлов |
| **Скрипт (.gd)** | GDScript — логика, похож на Python |
| **Autoload** | Глобальный сервис, доступен отовсюду (`WorldState`, `Inventory`, `DialogueUI`) |
| **Сигнал** | «Событие»: например, флаг мира изменился |

## Что запускается

Главная сцена: `scenes/world/valley_slice.tscn`  
Она собирает прототип из скрипта `scripts/world/main_slice.gd` (цветные плейсхолдеры).

Глобальные системы (Проект → Параметры проекта → Autoload):

- `WorldState` — флаги поселения + сохранение
- `Inventory` — предметы
- `DialogueUI` — окно диалога

## Как пройти слайс

1. Поговорить с **Петром** (площадь).
2. Поговорить с **Софьей** (пекарня).
3. Разобрать **забор** (дерево) и **телегу** (металлолом).
4. У **верстака** в мастерской сделать дверцу (`E`).
5. Установить дверцу в **печь**.
6. **Лечь спать** — утром пекарня открыта, жители у входа.

Цель на экране подсказывает следующий шаг.

## Если что-то красное внизу

Открой вкладку **Вывод / Debugger**. Чаще всего: опечатка в пути `res://...` или скрипт не сохранился. После правок с нашей стороны просто перезапусти сцену (F5).

## Сброс сохранения прототипа

Сейв лежит в user-данных Godot (`user://world_state.json`), не в папке проекта.  
Чтобы начать с нуля: Проект → Открыть папку данных пользователя → удали `world_state.json` → F5.
